# IDE setups

User setup for VS Code and Cursor, copied from the machine that last updated this folder. Each product directory holds `settings.json`, `keybindings.json`, and `extensions.txt` (one extension id per line).

On a new machine, copy `settings.json` and `keybindings.json` into that product's user settings directory, then install every id in `extensions.txt`. Pick the directory for the OS you are on. Leave extension binaries, caches, history, workspace storage, and account config off this snapshot.

Windows terminal profiles and `ctrl` / `alt` keybindings are stored as written. Change them on the new machine if they do not fit.
